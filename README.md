## 📖 Περιγραφή & Σκοπός

Το **EduHTML Studio** αναπτύχθηκε για να καλύψει τις ανάγκες διδασκαλίας και εργαστηριακής εξάσκησης των μαθητών της Δευτεροβάθμιας Εκπαίδευσης:
- **Α' Τάξη Γενικού Λυκείου (ΓΕΛ):** Μάθημα «Εφαρμογές Πληροφορικής» (Εισαγωγή στις γλώσσες σήμανσης HTML5).
- **Τομέας Πληροφορικής ΕΠΑΛ:** Ειδικότητες Πληροφορικής (Μαθήματα «Σχεδίαση & Ανάπτυξη Ιστοτόπων», HTML5, CSS3, Responsive Design).

Στόχος του λογισμικού είναι να παρέχει ένα **ολοκληρωμένο, εύχρηστο και ασφαλές offline περιβάλλον**, χωρίς περίπλοκες ρυθμίσεις ή απαιτήσεις δικτύου.

### 🏫 Μαζική Εγκατάσταση στο Εργαστήριο (MSI)

Από γραμμή εντολών **ως διαχειριστής** σε κάθε υπολογιστή (ή μέσω εργαλείου απομακρυσμένης διανομής):

```bat
:: Σιωπηλή εγκατάσταση για όλους τους χρήστες
msiexec /i "EduHTML.Studio-1.9.0.msi" /qn /norestart

:: Σιωπηλή εγκατάσταση με αρχείο καταγραφής (για διάγνωση προβλημάτων)
msiexec /i "EduHTML.Studio-1.9.0.msi" /qn /norestart /l*v "%TEMP%\eduhtml-install.log"

:: Σιωπηλή απεγκατάσταση
msiexec /x "EduHTML.Studio-1.9.0.msi" /qn /norestart
```

- **Group Policy (GPO):** Αντιγράψτε το `.msi` σε κοινόχρηστο φάκελο δικτύου και προσθέστε το στο *Computer Configuration → Policies → Software Settings → Software installation*.
- **Αναβαθμίσεις:** Κάθε νέα έκδοση MSI αντικαθιστά αυτόματα την προηγούμενη (σταθερό UpgradeCode), χωρίς να χρειάζεται πρώτα απεγκατάσταση.
- Οι ρυθμίσεις και οι φάκελοι εργασιών (`Έγγραφα\mywebpages`) παραμένουν ξεχωριστοί για κάθε μαθητικό λογαριασμό.

> 💡 **Σημείωση:** Για άμεση εκτέλεση από τον πηγαίο κώδικα, αρκεί ένα διπλό κλικ στο αρχείο **[`start.bat`](start.bat)**.

## ✨ Κύριες Δυνατότητες & Χαρακτηριστικά

### 1. 🪟 Ειδικές Βελτιστοποιήσεις για Windows 11
- **Ενσωμάτωση Microsoft Edge (`msedge.exe`):** Άμεση κλήση του προεγκατεστημένου Edge των Windows 11 για 100% πιστή προβολή.
- **Windows 11 Fluent UI & Styling:** Υποστήριξη Mica effect, σκοτεινού/φωτεινού θέματος, Windows Snap Layouts (`Win + Βέλη`) και σύγχρονων γραμματοσειρών (`Segoe UI Variable`, `Cascadia Code`).
- **Αποθήκευση:** στο ribbon (καρτέλα «Κεντρικό») τα κουμπιά **Αποθήκευση** (Ctrl+S) και **Αποθήκευση ως…** (Ctrl+Shift+S)· η γραμμή κατάστασης δείχνει αν υπάρχουν μη αποθηκευμένες αλλαγές.
- **Δουλεύει πάντα στο ανοιχτό αρχείο:** η καρτέλα του editor και ο τίτλος του παραθύρου δείχνουν το όνομα του αρχείου (π.χ. `askisi.html`) και η μπάρα της προεπισκόπησης τη διαδρομή του. Η **Προβολή στον Browser** αποθηκεύει και ανοίγει το ίδιο το αρχείο (στη λειτουργία «Προχωρημένος» αποθηκεύει και το CSS)· μια σελίδα που δεν έχει αποθηκευτεί ακόμα ζητά πρώτα όνομα.
- **Πολλά αρχεία σε καρτέλες:** κάθε αρχείο που ανοίγει (ή κάθε «Νέο») μπαίνει σε δική του καρτέλα· ένα αρχείο που είναι ήδη ανοιχτό δεν ανοίγει δεύτερη φορά. Η **προεπισκόπηση δείχνει πάντα το αρχείο με το focus** (με focus σε CSS, την τελευταία σελίδα HTML με αυτό το CSS). Τελεία στην καρτέλα = μη αποθηκευμένες αλλαγές· κλείσιμο με ✕, μεσαίο κλικ ή **Ctrl+W** (ρωτά αν υπάρχουν αλλαγές), εναλλαγή με **Ctrl+Tab**. Στη λειτουργία «Αρχάριος» φαίνονται μόνο οι καρτέλες HTML.
- **Σύνδεση HTML ↔ CSS (Προχωρημένος):** η προεπισκόπηση εφαρμόζει το CSS **μόνο μέσω του `<link rel="stylesheet" href="…">`** της σελίδας, όπως ένας browser: ένα αρχείο CSS ανοιχτό σε καρτέλα δίνει το περιεχόμενό του (και τις αλλαγές που δεν έχουν αποθηκευτεί), αλλιώς φορτώνεται από τον δίσκο. Η μπάρα ελέγχου προειδοποιεί όταν η σελίδα δεν συνδέεται με CSS ή όταν το `href` δείχνει σε αρχείο που δεν υπάρχει· το κουμπί **«Σύνδεση με CSS»** (και το δεξί κλικ) προσθέτει τη γραμμή `<link>` στο `<head>`.
- **Εισαγωγή εικόνας (`<img src="">`):** κουμπί **Εικόνα** στο ribbon, στο δεξί κλικ, στο μενού Επεξεργασία (**Ctrl+Shift+P**) και στην κάρτα `<img>` του Οδηγού Εντολών. Ο μαθητής διαλέγει την εικόνα από τον διάλογο των Windows και η διαδρομή μπαίνει μέσα στα `""` του `src`:
  - Αν ο κέρσορας είναι μέσα σε ένα `<img>`, συμπληρώνεται το `src` του· αλλιώς μπαίνει ολόκληρη η ετικέτα `<img src="..." alt="">` με τον κέρσορα μέσα στο `alt`.
  - **Ίδιος φάκελος με τη σελίδα:** μόνο το όνομα (`eikona.jpg`). **Υποφάκελος:** σχετική διαδρομή (`images/eikona.jpg`). **Αλλού:** ολόκληρη η διαδρομή (`file:///C:/Φωτο/eikona.jpg`) και σχετική ειδοποίηση, γιατί αυτή δουλεύει μόνο σε αυτόν τον υπολογιστή.
- **Θέματα & Χρώμα Κεφαλίδας (όπως στο myGlossa):** 8 θέματα — τα προεπιλεγμένα **Φωτεινό / Σκοτεινό** και θέματα τύπου Android Studio (**Dark, Darcula, Islands Darcula, Light, IntelliJ Light, Islands Light**). Επιλογή από το ribbon, από το μενού **Προβολή → Θέμα εμφάνισης** ή από τις Ρυθμίσεις· εναλλαγή φωτεινό ↔ σκοτεινό με **Ctrl+Shift+T**. Η γραμμή τίτλου, οι καρτέλες και το ribbon έχουν **ένα χρώμα** (Ρυθμίσεις: «Ίδιο με το θέμα», 13 έτοιμα χρώματα ή οποιοδήποτε άλλο) με προαιρετική **διαβάθμιση (gradient)** δύο χρωμάτων και κατεύθυνση. Τα γράμματα και τα κουμπιά του παραθύρου προσαρμόζονται μόνα τους ώστε να διαβάζονται.
- **Πλήρης Οθόνη & Ελαχιστοποίηση:** Ειδικό κουμπί πλήρους οθόνης (`⛶`) και συμβατότητα με τις γνωστές λειτουργίες παραθύρου των Windows 11.
- **Μενού με Καρτέλες (Ribbon):** Οι ενέργειες είναι οργανωμένες σε καρτέλες, ώστε η οθόνη να μένει καθαρή:
  - **🏠 Κεντρικό:** Νέο, Άνοιγμα, Αποθήκευση, Αποθήκευση ως · Προβολή στον Browser · Οδηγός Εντολών, Μορφοποίηση · Εισαγωγή εικόνας
  - **🎒 Εργασία:** Πρότυπα · Εξαγωγή ZIP, e-Class
  - **🎨 Εμφάνιση:** Μέγεθος γραμμάτων · Θέμα (εναλλαγή φωτεινό/σκοτεινό και επιλογή θέματος) · Χρώμα κεφαλίδας · Πλήρης Οθόνη
  - **⚙️ Ρυθμίσεις & Βοήθεια:** Ρυθμίσεις · Συντομεύσεις, Σχετικά

### 2. 🌱 Διπλή Λειτουργία Εργασίας (Modes)
- **🌱 Λειτουργία Αρχάριος (Ενιαίο Αρχείο):** Ο μαθητής γράφει ένα ενιαίο `index.html` με ενσωματωμένο εσωτερικό CSS (`<style>...</style>`). Ιδανικό για τα πρώτα εισαγωγικά μαθήματα.
- **🚀 Λειτουργία Προχωρημένος (Multi-Tab):** Διαχωρισμένες καρτέλες για `index.html` και `style.css` με αυτόματη συνένωση κατά την εκτέλεση.
- **Προσαρμογή Διεπαφής:** Από τις Ρυθμίσεις (`⚙️`), ο καθηγητής μπορεί να αποκρύψει τα κουμπιά επιλογής λειτουργίας και τα πρότυπα, προσφέροντας μια υπεραπλουστευμένη οθόνη για αρχάριους μαθητές.

### 3. 💡 Έξυπνη Πρόταση Εντολών HTML & CSS (Autocomplete στυλ Notepad++)
- **Αυτόματη Εμφάνιση Προτάσεων:** Καθώς ο μαθητής ανοίγει ένα tag (πληκτρολογώντας `<`) ή ξεκινά τη δακτυλογράφηση, εμφανίζεται αυτόματα αναδυόμενο παράθυρο με καθαρά ονόματα ετικετών HTML5 (π.χ. `h1`, `p`, `a`, `table`, `img` κ.ά.) με το χαρακτηριστικό εικονίδιο του Notepad++.
- **Αυτόματο Κλείσιμο Ετικετών & Τοποθέτηση Κέρσορα:** Με την επιλογή οποιασδήποτε διπλής ετικέτας, τοποθετείται αυτόματα το ζεύγος (π.χ. `<h1></h1>`) και ο κέρσορας τοποθετείται αυτόματα στο κέντρο για άμεση πληκτρολόγηση.
- **Υποστήριξη CSS:** Στην καρτέλα `style.css` (ή στο εσωτερικό CSS), προτείνονται αυτόματα όλες οι ιδιότητες CSS (π.χ. `color`, `background-color`, `font-size`, `display` κ.ά.).
- **Συντόμευση Πληκτρολογίου:** Άμεση εμφάνιση προτάσεων ανά πάσα στιγμή με `Ctrl + Space` ή `Alt + Space`.

### 4. 🌐 Ενσωματωμένος & Εξωτερικός Browser
- **Live Preview:** Άμεση ανανέωση της ιστοσελίδας σε πραγματικό χρόνο καθώς πληκτρολογεί ο μαθητής.
- **Επιλογή Εξωτερικού Browser:** Δυνατότητα ορισμού του αγαπημένου browser από τις Ρυθμίσεις (**Edge**, **Chrome**, **Firefox**, **Brave** ή Windows Default). Το κουμπί προσαρμόζεται αυτόματα (π.χ. *«Προβολή στον Edge»*).
- **Σύνδεση με το e-Class (`🏫 e-Class`):** Άμεσο κουμπί για άνοιγμα της επίσημης πύλης **`https://eclass.sch.gr`** του Πανελλήνιου Σχολικού Δικτύου.

### 5. 📁 Οργάνωση Αρχείων & Αυτόματος Φάκελος
- **Αυτόματος Φάκελος `Documents/mywebpages`:** Στην πρώτη εκκίνηση δημιουργείται αυτόματα φάκελος στα Έγγραφα του χρήστη.
- **Άνοιγμα & Αποθήκευση:** Οι διάλογοι αρχείων ανοίγουν απευθείας στον προεπιλεγμένο φάκελο, διευκολύνοντας τους μαθητές στην εύρεση των εργασιών τους.
- **Δυνατότητα Αλλαγής:** Ο φάκελος αλλάζει ανά πάσα στιγμή μέσα από τις Ρυθμίσεις (`⚙️`).
- **Καθαρός Σκελετός στο «📄 Νέο»:** Το κουμπί «Νέο» παράγει έναν καθαρό βασικό σκελετό (`<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, `<body>`) χωρίς περιττά στοιχεία.

### 6. 📖 Διαδραστικός Οδηγός Εντολών (Cheat Sheet) στα Ελληνικά
- Πλήρης κατάλογος όλων των ετικετών HTML5, ιδιοτήτων CSS3 και βασικών εντολών JavaScript του αναλυτικού προγράμματος.
- Επεξηγήσεις στα απλά Ελληνικά, σύνταξη, έτοιμα παραδείγματα και ένδειξη επιπέδου (ΓΕΛ / ΕΠΑΛ).
- Κουμπί **«↵ Εισαγωγή στον Editor»** για αυτόματη εισαγωγή του κώδικα στο σημείο του κέρσορα.
- Ξεκινά κλειστός κατά την εκκίνηση και ανοίγει με το κουμπί **📚** ή τη συντόμευση `Ctrl + G`.

### 7. 🔍 Ενισχυμένος Εκπαιδευτικός Έλεγχος & Βοηθός Λαθών
- **Έλεγχος Ελληνικών Χαρακτήρων στα Tags:** Εντοπίζει άμεσα αν ένας μαθητής πληκτρολόγησε ετικέτα με ελληνικά (π.χ. `<τίτλος>`, `<δομή>`) και προειδοποιεί στα Ελληνικά.
- **Έλεγχος Ορθογραφίας Ετικετών:** Εντοπίζει τυπογραφικά λάθη (π.χ. `<tutle>`, `<basd>`) έναντι του επίσημου HTML5 προτύπου.
- **Έλεγχος Δομής & Ιεραρχίας:** Ελέγχει τη σωστή σειρά `<head>` και `<body>`, απαγορεύει κώδικα μετά το `</html>`, και επισημαίνει μη κλεισμένες ετικέτες.
- **Ευανάγνωστη Μπάρα:** Μεγάλη γραμματοσειρά (+4pt), δυνατότητα εμφάνισης δύο γραμμών μηνύματος και πλήρη επεξήγηση στο πέρασμα του ποντικιού (Mouseover Tooltip).

- **Εξαγωγή σε ZIP:** για υποβολή στο e-Class ή παράδοση στον καθηγητή, με τρεις επιλογές: **το τρέχον αρχείο**, **όλα τα ανοιχτά αρχεία** (με τους υποφακέλους τους, π.χ. `css/style.css`) ή **ολόκληρος ο φάκελος της εργασίας** (μαζί με εικόνες και υποφακέλους). Τα αρχεία που δεν έχουν αποθηκευτεί δεν μπαίνουν· όσα έχουν μη αποθηκευμένες αλλαγές αποθηκεύονται πρώτα (επιλογή).
- **Μορφοποίηση Κώδικα (Beautify):** Αυτόματη στοίχιση των ετικετών (2 διαστήματα) με το πάτημα ενός κουμπιού.

- **Δεξί Κλικ σε Όλη την Εφαρμογή:** Υποστήριξη σε πεδία αναζήτησης και εισαγωγής κειμένου (Αποκοπή/Αντιγραφή/Επικόλληση), σε επιλεγμένο κείμενο οδηγού/καρτελών, στο περιβάλλον εργασίας καθώς και μέσα στο ενσωματωμένο Live Preview.
- **Windows 11 Acrylic Styling:** Σύγχρονη Fluent εμφάνιση με εφέ θολότητας (blur), κατάλληλο θέμα (σκοτεινό/φωτεινό) και ευκρινείς ετικέτες συντομεύσεων πληκτρολογίου για εκπαιδευτική εξοικείωση των μαθητών.

## 🚀 Οδηγίες Εγκατάστασης & Εκτέλεσης

### Απαιτήσεις Συστήματος
- **Λειτουργικό Σύστημα:** Windows 11 (64-bit)
- **Node.js:** v18+ (για εκτέλεση από τον πηγαίο κώδικα)

### Εκτέλεση μέσω Git & Node.js:
```bash
# 1. Κλωνοποίηση του αποθετηρίου
git clone https://github.com/pliroforikos/myHTML.git

# 2. Μετάβαση στον φάκελο
cd myHTML

# 3. Εγκατάσταση εξαρτήσεων
npm install

# 4. Εκκίνηση της εφαρμογής
npm start
# Ή διπλό κλικ στο start.bat
```

### Δημιουργία Εκτελέσιμων Windows (Setup Installer, Portable & MSI):
```bash
npm run dist        # Setup, Portable και MSI
npm run dist:msi    # Μόνο το MSI
```
Η εντολή παράγει αυτόματα στον φάκελο `dist/`:
- **`EduHTML.Studio-Setup-1.9.0.exe`**: Κανονικός εγκαταστάτης Windows (NSIS) με δημιουργία συντομεύσεων στην Επιφάνεια Εργασίας και το Μενού Έναρξης.
- **`EduHTML.Studio-Portable-1.9.0.exe`**: Αυτόνομη φορητή έκδοση (Portable), ιδανική για χρήση από USB flash drive στα σχολικά εργαστήρια χωρίς ανάγκη εγκατάστασης ή δικαιωμάτων διαχειριστή.
- **`EduHTML.Studio-1.9.0.msi`**: Πακέτο Windows Installer για μαζική, σιωπηλή εγκατάσταση σε όλους τους χρήστες του υπολογιστή (το WiX Toolset κατεβαίνει αυτόματα από το electron-builder).

### Δημοσίευση release (για να δουν την ενημέρωση οι εγκατεστημένες εφαρμογές)

Η ενημέρωση μέσα από την εφαρμογή διαβάζει το GitHub Release της τελευταίας έκδοσης. Σε κάθε release (tag `vX.Y.Z`, ίδιο με το `version` του `package.json`, όχι draft/prerelease) ανεβάζετε από το `dist/` **και τα πέντε** αρχεία:

```bash
gh release create vX.Y.Z --title "..." --notes-file notes.md \
  "dist/EduHTML.Studio-Setup-X.Y.Z.exe" \
  "dist/EduHTML.Studio-Setup-X.Y.Z.exe.blockmap" \
  "dist/EduHTML.Studio-Portable-X.Y.Z.exe" \
  "dist/EduHTML.Studio-X.Y.Z.msi" \
  "dist/latest.yml"
```

- Το `latest.yml` είναι αυτό που διαβάζει ο ενημερωτής (έκδοση, sha512 του Setup)· το `.blockmap` επιτρέπει διαφορική λήψη (πολύ μικρότερη).
- Τα ονόματα των αρχείων **δεν έχουν κενά** (ορίζονται στο `package.json`, `artifactName`): το GitHub αλλάζει τα κενά σε τελείες και τότε το `latest.yml` δεν θα έδειχνε στο σωστό αρχείο.
- Το `npm run dist` δεν ανεβάζει τίποτα (`--publish never`).
